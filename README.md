## Projeto: Análise Salarial em Carreiras de Dados (2020–2024)

Repositório do projeto elaborado pelo Grupo 1 do Programa CAIXAVERSO - Módulo "Técnicas de Programação I (PY)"

## Descrição

Este projeto realiza uma análise exploratória completa do dataset Data Science Salaries, investigando fatores como cargo, modalidade de trabalho, país, porte da empresa e nível de experiência influenciam os salários na área de dados entre 2020 e 2024.
Foram desenvolvidos notebooks organizados por perguntas de negócio, funções reutilizáveis em módulos Python e visualizações que permitem interpretar tendências reais do mercado de trabalho em tecnologia.

A análise também examina evolução temporal, diferenças entre cargos, impacto do trabalho remoto, variações salariais por país e mudanças estruturais no mercado. O objetivo é responder perguntas práticas e relevantes para profissionais e empresas, com base em dados reais e atualizados.

## Perguntas Respondidas

1. Progressão salarial por nível de experiência
2. Diferença salarial entre trabalho remoto, híbrido e presencial
3. Relação entre país, modalidade e salário
4. Comparativo entre cargos (DA, DS, DE, MLE)
5. Evolução temporal de salários e modalidades (2020–2024)
6. Porte da empresa e salário (S, M, L)

## Três Principais Conclusões

1. Trabalho remoto paga mais na maioria dos países, mas o presencial volta a crescer a partir de 2023.
2. Data Engineer é o cargo com mais vagas, enquanto Machine Learning Engineer tem os maiores salários.
3. Empresas de porte médio pagam mais em praticamente todos os níveis, especialmente para profissionais seniores.
